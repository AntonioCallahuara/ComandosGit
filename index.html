Practica Git & Github

01

INICIALIZAR PROYECTO

mkdir proyecto-git
cd proyecto-git
git init

02

PRIMER COMMIT LOCAL

git add .
git commit -m "Proyecto Base"

03

CREAR REPOSITORIO GITHUB (WEB)

Crear un repositorio remoto en GitHub

04

VINCULAR CON LA NUBE (GITHUB)

git remote add origin URL_DEL_REPO_REMOTO

05

EL GRAN PUSH

git push -u origin master

06

Actualización (Nuevos cambios)

git add.
git commit -m "Nuevos cambios"
git push origin master
